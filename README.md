# Notion Task Manager App // Productivity & Task Management Board UI

A high-performance, minimalist workspace and task management UI portfolio concept inspired by the Notion ecosystem. Engineered for personal organization, Kanban workflows, and project tracking with a clean studio aesthetic and responsive layout.

---

##  Key Architectural Features
- **Notion-Style Workspace Aesthetic:** Minimalist dark/light mode balance featuring dynamic Kanban boards, task status tags, and distraction-free document views.
- **Pure Vanilla JavaScript & Tailwind:** Zero heavy dependencies to guarantee lightning-fast page loading and rapid DOM manipulation.
- **Fully Responsive Layout:** Seamlessly optimized across mobile, tablet, and high-resolution desktop viewports.

---

## Technology Stack
- **Markup:** HTML5 (Semantic & Accessible)
- **Styling:** Tailwind CSS (Utility-first framework)
- **Scripting:** Pure Vanilla JavaScript (ES6+)
